# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform launched by Amazon in 2006. It provides a broad range of cloud services for computing, storage, databases, networking, security, analytics, artificial intelligence, and other business needs. AWS supports organizations ranging from startups to large enterprises and government institutions.

## Global Infrastructure

AWS operates a global cloud infrastructure organized into geographic Regions and Availability Zones. AWS also provides additional infrastructure such as Local Zones and edge locations to help applications serve users with lower latency. The AWS infrastructure is designed to support scalability, availability, and reliable deployment across different geographic locations.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can select AWS Regions, create and configure resources, monitor services, and manage their cloud infrastructure through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity in the AWS Cloud. It allows organizations to run virtual servers and applications.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for storing and retrieving data such as documents, images, backups, and application files.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) is a managed database service that simplifies the setup, operation, and scaling of relational databases.

### 4. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows organizations to create a logically isolated virtual network where AWS resources can be deployed and controlled.

## Three Advantages

1. **Scalability** – AWS allows organizations to increase or decrease cloud resources according to their workload requirements.
2. **Global Infrastructure** – AWS provides infrastructure in many geographic locations, supporting applications that need global availability and lower latency.
3. **Broad Service Selection** – AWS offers a wide range of services covering computing, storage, databases, networking, security, analytics, and artificial intelligence.

## Typical Enterprise Use Cases

AWS can be used by enterprises for application hosting, data storage and backup, database management, website and e-commerce platforms, disaster recovery, data analytics, artificial intelligence, and application modernization.
