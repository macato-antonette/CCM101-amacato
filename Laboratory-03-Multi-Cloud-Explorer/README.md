# Laboratory 03 - Multi-Cloud Explorer

## Checkpoint 7 – Linux Investigation

### Operating System

The Linux environment is running **Ubuntu 24.04.4 LTS (Noble Numbat)**.

### CPU Information

The system uses an **Intel Xeon E312xx (Sandy Bridge, IBRS update)** processor. The environment has **1 CPU** and is running on a KVM virtualized environment.

### Memory

The system has **1.9 GiB of total memory**, with approximately **1.5 GiB available**.

### Disk Space

The main filesystem `/dev/vda1` has **19 GB of total disk space**, with **5.4 GB used** and approximately **13 GB available**. It is currently using about **30%** of the disk space.

### Cloud Hosting Options

If this Linux server were migrated to the cloud, it could be hosted using the following services:

- **AWS:** Amazon EC2
- **Microsoft Azure:** Azure Virtual Machines
- **Google Cloud:** Compute Engine

These services provide virtual machine infrastructure capable of running Linux-based operating systems and applications.
