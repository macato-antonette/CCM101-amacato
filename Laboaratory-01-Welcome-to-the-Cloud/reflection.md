# Reflection

This laboratory activity gave me practical experience in working with a cloud-based Linux environment. I learned how to access Ubuntu, create and manage a Linux user, configure sudo access, and use basic Linux commands.

I also learned how to gather system information such as the Linux distribution, kernel version, CPU information, memory, and available disk space. Creating directories and Markdown files helped me understand how files can be organized in a Linux environment.

Another important lesson was learning how to use GitHub as a portfolio for my Cloud Computing activities. I learned how to create a repository, organize files, and document my work using Markdown.

Overall, this activity improved my confidence in using Linux and introduced me to practical cloud computing workflows that I can use in future IT projects.
